AI-gebruik

Voor het blur effect bij de woorden 'DNS-blokkade' en 'IP-blokkade' heb ik ChatGPT gebruikt. De HTML en CSS code voor dit effect is met behulp van ChatGPT gemaakt.

Ook heb ik met hulp van ChatGPT de CSS-selector :has() gebruikt. Hiermee selecteer ik het figure-element met de wereldkaart over internetcensuur, zodat ik de linker- en rechtermarge van dit element kan aanpassen.

Hulp bij het programmeren

Tijdens het ontwerpen van mijn website heb ik hulp gekregen van een vriend die software engineer is. Hij heeft mij uitgelegd wat het HTML element Span; is en hoe ik dit met CSS kan gebruiken om bepaalde delen van mijn website vorm te geven. Dankzij zijn uitleg heb ik geleerd hoe ik dit element zelf kan toepassen in mijn website.
